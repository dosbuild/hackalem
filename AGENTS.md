# Alem integration instructions

The active product is the geographically grounded suspended Astana city, Aya, resident
encounters and five-decision scenario in src/. Root README.md owns startup and
deployment; docs/release.md owns current release status; src/world/contract.ts
owns the application/world boundary; src/domain/scenario.ts owns executable data.
The canonical supplied specification is preserved in docs/scenario/source/.

Preserve one authoritative plan, exact eight-quarter calculation, 100-unit budget,
five distinct initiatives, maximum two per policy area, and all scoped conflicts.
Do not make visual presentation or authored residents affect numerical results.

The sphere and custom landmark showcase are superseded by the suspended city in
`src/world/city-math.js`, `city-gl.js` and `alem-runtime.js`. Do not restore them.
District colours are geographic identities; keep them stable across results.
The map owns the viewport; panels overlay it. `projection.js` is the shared camera
frame for the renderer, native residents, labels, conversation and picking. Physical
projects and 3D residents use the existing city depth pass.
`docs/consequences/README.md` owns geographic placement, choreography and the
14 native treatments. Regenerate placements only with source geometry checks;
keep physical scale separate from cartographic macro signals. Never add independent overlay zoom easing.
`npm run test:fullscreen` records the complete journey and audits moving anchors.
See `docs/fullscreen/README.md` for current composition and verification.
`npm run test:budget` checks the treasury and records the pointer sequence;
`npm run test:journey` checks the complete game journey. Fluid allocations
live in the existing app reducer; free + fluid + locked must always equal 100.
Never let a budget gesture edit committed decisions or scale project effects.

The retired winter courtyard and spherical prototypes remain in the separate
development repository, outside this production source and history. Do not restore
their entry points, authoring assets, or generated captures into this application.
Do not publish source references, original screenshots, archives, credentials or
raw national data. scripts/release/build.mjs defines the runtime asset allowlist.

Run npm run verify and the documented production browser checks for relevant
changes. Preserve existing agents' uncommitted work and use explicit handoffs.
