# Two worlds, one exact game

Астана and Хандық each have their own five decisions, treasury, resident stories,
chronicle, saved attempt and camera. The numerical rules and initiative effects
are identical. Хандық translates those choices into an authored fictional city of
teaching yurts, paths, gardens, healers, petitioners and a khan’s court.

The current original drawing language is [River atlas](river-atlas.md).
[Current release status](release.md) names the tested build and verification;
[the root README](../README.md) owns connected and static commands.
[Historical material vocabulary](khanate-art-direction.md) records the authored
geometry’s sources without redistributing museum photographs or models.

Use the permanent world selector to enter either world directly. `npm run build`
produces the connected package; `npm run build:static` produces the complete core
game for plain HTTPS static hosting. Only the entered world downloads its geometry.
Static play uses local explanations and records; connected publication remains
explicit and requires durable single-writer storage.

Regenerate the native previews after changing models, materials, projection or
exporter source. Run both static journeys, world-switch/resource lifecycle,
recovery, reduced-motion and normal-motion checks against the final package.
Older candidate measurements are not acceptance of this release.
